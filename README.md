# Portfolio

This project has been converted into a complete Next.js app.

## What changed

- Replaced the old static HTML entry points with Next.js routes for the home page, experience, education, and projects.
- Kept the portfolio content, styling, and contact form behavior in the app router structure.
- Stored all image assets in the public directory so the app uses a single source for media files.

## Run locally

- Install dependencies: `npm install`
- Start the development server: `npm run dev`
- Build for production: `npm run build`
